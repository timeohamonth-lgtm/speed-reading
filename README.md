# Lecture Rapide

Application de lecture rapide (RSVP) : affichage des mots un par un pour lire de longs textes plus vite.

## Utilisation

- Ouvrir `index.html` dans n'importe quel navigateur (ordinateur ou smartphone) — ou charger un **📜 Texte d'essai** en un clic.
- Coller un texte, cliquer sur **▶️ Démarrer**, régler la vitesse avec le curseur (50 à 900 mots/min).
- Contrôles : ▶️/⏸️ lecture-pause, ⏮️/⏭️ naviguer, 🔄 recommencer, ✏️ modifier le texte.
- Raccourcis clavier : `Espace` lecture/pause, `←`/`→` mot précédent/suivant, `↑`/`↓` vitesse, `R` recommencer, `Échap` éditer.

Aucune dépendance ni build.

## Installer comme application (PWA)

Sur smartphone : ouvrir le site, puis **"Ajouter à l'écran d'accueil"** (via le menu du navigateur). L'application s'installe avec son icône, s'ouvre en plein écran et fonctionne **hors ligne** (service worker).
